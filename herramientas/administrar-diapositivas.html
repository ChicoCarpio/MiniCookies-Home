    Cómo reordenar o quitar diapositivas de una presentación

    Permite cambiar el orden de las diapositivas de una presentación de PowerPoint (.pptx) o quitar las que no necesitás, sin abrir PowerPoint. Entra un archivo .pptx y sale otro .pptx con las diapositivas que dejaste en el orden que elegiste. Es práctico para armar una versión corta de una presentación, reordenar una charla o sacar diapositivas que no querés compartir.

    Paso a paso

    1. Arrastrá el archivo .pptx a la zona de carga o hacé clic para elegirlo. La herramienta lee la presentación y lista las diapositivas.
    2. Cada diapositiva aparece como «Diapositiva N» y, si tiene texto, con los primeros caracteres del primer texto que encuentra. Arrastrá cada fila para cambiar su posición.
    3. Para quitar una diapositiva, tocá la ✕ de su fila. La barra de deshacer y rehacer permite recuperar lo que quitaste o volver al orden anterior.
    4. Tocá «Descargar reordenada». Cuando termina aparece el enlace «Descargar PowerPoint» y el archivo se llama «presentacion-reordenada.pptx».

    Consejos

    • La etiqueta de cada fila usa el primer texto de la diapositiva, así que sirve para reconocerlas aunque no tengan título. Si una diapositiva solo tiene imágenes, aparece solo con su número original.
    • Al quitar diapositivas, también se borra su contenido interno (imágenes y notas) y se las saca de las secciones y de las presentaciones personalizadas.
    • Las notas y las diapositivas ocultas de las que quedan se conservan.
    • Si una diapositiva que queda tiene un enlace a una que quitaste, ese enlace se elimina y el texto queda como texto normal (se explica en la burbuja «?» de la página).
    • Siempre se parte del archivo original, por lo que podés generar varias versiones distintas sin acumular cambios.

    Preguntas frecuentes

    ¿Puedo dejar el archivo sin diapositivas?

    No. Si quitás todas, el botón de descargar queda deshabilitado.

    ¿Se pierde el formato de las diapositivas?

    La herramienta no las vuelve a dibujar: reordena y elimina partes del propio archivo, de modo que el contenido de las que quedan no cambia.

    ¿Acepta archivos .ppt antiguos?

    No, solo .pptx.

    ¿Puedo duplicar una diapositiva?

    No, solo reordenar y quitar.
