Cómo reordenar o eliminar páginas de un PDF

Permite reordenar y eliminar las páginas de un PDF viendo sus miniaturas. Entra un PDF y sale un PDF nuevo con las páginas que dejaste, en el orden que elegiste. Sirve para sacar páginas en blanco o sobrantes, pasar una hoja al principio o corregir un escaneo que quedó desordenado.

Paso a paso

  1. Arrastrá el PDF a la zona de carga o hacé clic para elegirlo. Se generan las miniaturas de todas las páginas (en un PDF grande puede tardar).
  2. Cada miniatura trae la etiqueta «Original: página N». Arrastrá las miniaturas para cambiar el orden.
  3. Tocá la ✕ de una miniatura para eliminar esa página. Si te equivocás, usá los botones de deshacer y rehacer, o «Restaurar orden original» para volver a todas las páginas en su orden inicial.
  4. Tocá «Guardar PDF modificado» y después el enlace «Descargar PDF modificado». El archivo se llama «documento-modificado.pdf».

Consejos

  • Sobre las miniaturas hay un selector con «Cuadrícula» y «Lista». El modo que elegís se recuerda en este navegador.
  • «Restaurar orden original» no vuelve a leer el archivo y también se puede deshacer.
  • El PDF nuevo se arma copiando las páginas elegidas del original, por lo que el contenido de cada página queda igual.
  • En el celular podés reordenar arrastrando con el dedo.

Preguntas frecuentes

¿Puedo quitar todas las páginas?

No. Si no queda ninguna, se avisa que no hay páginas para guardar.

¿Puedo girar páginas con esta herramienta?

No; solo reordena y elimina.

¿Funciona con PDF protegidos con contraseña?

No hay un campo para ingresar contraseña; es probable que el PDF no se pueda abrir.

¿Se pierden los marcadores o enlaces internos?

Al copiar solo las páginas a un documento nuevo, es posible que no se conserven elementos del documento como índices o marcadores.
