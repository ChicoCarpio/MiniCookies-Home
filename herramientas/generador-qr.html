Cómo crear un código QR a partir de un link o un texto

Un código QR convierte una dirección web o un texto corto en un dibujo que cualquier celular lee con la cámara. Es útil para llevar a alguien a tu sitio desde un cartel, una tarjeta o una presentación, para compartir una dirección sin dictarla, o para pasar un texto breve a otro dispositivo. Esta herramienta genera el QR en el momento y te deja descargarlo como imagen PNG.

Paso a paso

  1. Escribí o pegá el link o el texto en el campo «Texto o URL». Para un sitio web conviene incluir la dirección completa, con https://.
  2. Elegí el «Tamaño»: Pequeño (200px), Mediano (300px) o Grande (500px).
  3. Pulsá «Generar QR» o la tecla Enter. El código aparece debajo, rodeado de un margen blanco.
  4. Probalo con la cámara de tu celular y, si lee bien, usá «Descargar QR como imagen» para guardar el archivo codigo-qr.png.

Consejos

  • Para imprimir, elegí el tamaño Grande: tiene más píxeles y se imprime más nítido. En un cartel, dejá el código lo bastante grande como para leerlo desde la distancia a la que se va a escanear.
  • Al diseñar el material, no recortes el margen blanco ni pongas el código sobre un fondo con dibujos: el lector necesita buen contraste y esa zona libre alrededor para encontrarlo.
  • Un texto más corto produce un QR más simple, con módulos más grandes y más fácil de leer. Si tu link es larguísimo, acortalo antes.

Preguntas frecuentes

¿Por qué dice que el texto es demasiado largo?

Un código QR tiene un límite de datos. Si lo superás, la herramienta muestra un aviso en vez de generar algo ilegible; acortá el texto o usá un acortador de links.

¿El QR vence o deja de funcionar?

No. El código contiene el texto en sí, no depende de ningún servicio. Funciona mientras la dirección a la que apunta siga existiendo.

¿Puedo cambiar el contenido después de imprimirlo?

No: el contenido está dentro del dibujo. Si necesitás poder cambiar el destino más adelante, generá el QR con un link que vos controles y que luego puedas redirigir.
