    Espacio publicitario

    Cómo ver un archivo Excel o CSV sin abrir Excel

    Para mirar el contenido de una planilla sin tener Excel instalado, por ejemplo desde una computadora ajena o un celular. La herramienta abre archivos .xlsx, .xlsm, .xlsb, .xls, .ods y .csv y los muestra como una hoja de cálculo: con letras y números en los bordes, celda activa, selección de rangos, pestañas de hojas, zoom y barra de estado con recuento, suma y promedio. Es solo de lectura: el archivo no se modifica.

    Paso a paso

    1. Arrastrá el archivo a la zona «Arrastrá tu archivo acá o hacé clic para elegirlo». Mientras carga aparece «Preparando la hoja…».
    2. Recorré la hoja con el desplazamiento normal, hacé clic en una celda para ver su contenido y cambiá de hoja con las pestañas inferiores.
    3. Seleccioná un rango y usá «Copiar selección» para llevarlo al portapapeles; la barra de estado muestra recuento, suma y promedio de lo seleccionado.
    4. Si preferís una vista más simple (o la hoja no se dibuja bien), hacé clic en «Ver como tabla» para cambiar a una tabla con una pestaña por hoja; el mismo botón vuelve a la rejilla.

    Consejos

    • La rejilla permite buscar dentro de la hoja o en todo el libro, acercar y alejar con el zoom (50 a 200 por ciento) y pasar a pantalla completa.
    • Podés ordenar o filtrar lo que ves desde el encabezado de cada columna; el cambio es solo visual y el archivo no se modifica.
    • Las fórmulas se muestran como las guarda el archivo, en inglés (SUM, IF…) y con coma entre argumentos; Excel las traduce a tu idioma al abrir el original.
    • Los archivos con hojas ocultas las listan aparte como «Hojas ocultas». Si una hoja está vacía, se indica «Hoja vacía».
    • Para convertir a otro formato o editar el contenido, usá las otras herramientas de Excel / CSV del sitio.

    Preguntas frecuentes

    ¿Puedo editar la planilla?

    No, es un visor.

    ¿Qué formatos abre?

    .xlsx, .xlsm, .xlsb, .xls, .ods y .csv.

    ¿Qué pasa con las hojas muy grandes?

    Se dibuja solo la parte visible, por lo que el desplazamiento se mantiene fluido; en la vista de tabla se virtualizan las filas a partir de 200.

    ¿Para qué sirve «Ver como tabla»?

    Es una vista alternativa en texto, útil con lectores de pantalla o si la rejilla no se pudo cargar.
