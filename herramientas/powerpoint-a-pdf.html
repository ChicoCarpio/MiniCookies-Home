    Limitaciones

    • Primero se intenta renderizar las diapositivas reales (texto, formas, imágenes) y armar el PDF con eso — también se pueden descargar esas imágenes sueltas en un .zip.
    • Si el archivo no se puede renderizar bien, se genera igual un PDF con el texto de cada diapositiva en vez de fallar (se avisa cuál de los dos resultó). Si solo te interesa el texto, también está Extraer texto de PowerPoint.
    • Nota: como esto corre 100% en tu navegador (no en un servicio especializado en un servidor, como PowerPoint o LibreOffice reales), el resultado puede no ser 100% fiel al original — diapositivas con diseños complejos, animaciones o elementos poco comunes pueden verse distinto.

    Cómo convertir una presentación de PowerPoint a PDF

    Un PDF se ve igual en cualquier computadora o celular, no depende de que el destinatario tenga PowerPoint ni de que tenga instaladas las mismas fuentes. Es el formato más cómodo para enviar una presentación por correo, entregarla como tarea o imprimirla. Esta herramienta recibe un archivo .pptx, dibuja cada diapositiva y arma un PDF con una página por diapositiva. Además te ofrece las diapositivas como imágenes PNG en un .zip.

    Paso a paso

    1. Arrastrá tu archivo .pptx a la zona de carga o hacé clic para elegirlo. Solo se acepta ese formato.
    2. Pulsá «Convertir a PDF». Mientras trabaja ves el mensaje de progreso y, al terminar, una vista previa de las diapositivas.
    3. Leé el mensaje de resultado: te dice si el PDF se generó con las diapositivas reales, si algún elemento no se pudo dibujar o si solo se pudo guardar el texto.
    4. Descargá el PDF, que conserva el nombre de tu presentación con la extensión .pdf, o las imágenes en el .zip si las querés por separado.

    Consejos

    • Revisá la vista previa antes de enviar el PDF: los diseños complejos, las animaciones y algunos elementos poco comunes pueden verse distintos de como aparecen en PowerPoint.
    • Si tu archivo está en el formato antiguo .ppt, abrilo en PowerPoint y guardalo como .pptx antes de usar esta herramienta.
    • El .zip trae un PNG por diapositiva (diapositiva-01.png, diapositiva-02.png, etc.), útil para pegarlas en un documento, un correo o una publicación.

    Preguntas frecuentes

    ¿Por qué mi PDF solo tiene texto?

    Cuando una presentación no se puede dibujar, la herramienta no falla: genera igualmente un PDF con el texto de cada diapositiva y te avisa con un mensaje. Si lo único que necesitás es el texto, también existe la herramienta Extraer texto de PowerPoint.

    ¿Qué significa que algunos elementos «no se pudieron dibujar»?

    Que el PDF está hecho, pero faltan piezas puntuales, por ejemplo un SmartArt sin su dibujo guardado, un objeto incrustado o un gráfico que no se pudo leer. El mensaje indica cuántos fueron.

    ¿El resultado es idéntico a lo que muestra PowerPoint?

    No siempre. La conversión se hace dentro del navegador, sin el programa original, así que conviene comparar el PDF con tu presentación antes de entregarlo.
