Espacio publicitario

Los links usan el mismo formato de "ancla" que GitHub/GitLab (minúsculas, espacios reemplazados por guiones, sin puntuación) — funcionan al publicar el Markdown en esas plataformas o en cualquier visor que siga esa misma convención.

Cómo generar una tabla de contenidos de un Markdown

Un documento Markdown largo se navega mucho mejor con un índice al principio. Esta herramienta lee los encabezados (los que empiezan con # y también los subrayados con === o ---) y arma una lista con enlaces a cada uno, lista para pegar en el README o en la documentación. Podés pegar el texto o subir un archivo .md, y el resultado se puede copiar o descargar.

Paso a paso

  1. Arrastrá un archivo .md o .markdown a la zona, o escribí o pegá el contenido directamente en el cuadro «Markdown».
  2. Hacé clic en «Generar tabla de contenidos».
  3. Revisá el cuadro «Markdown con tabla de contenidos agregada»: el índice aparece al principio, con el título «Tabla de contenidos».
  4. Usá «Copiar resultado» o «Descargar .md» (documento-con-indice.md).

Consejos

  • Los enlaces siguen la regla de anclas de GitHub: minúsculas, espacios convertidos en guiones y sin signos de puntuación (salvo guiones y guiones bajos). Si dos títulos se llaman igual, el segundo recibe -1, el tercero -2, y así sucesivamente.
  • Los títulos dentro de bloques de código no cuentan, así que un comentario # algo en un ejemplo no genera una entrada falsa.
  • Si tu archivo empieza con metadatos YAML (el bloque entre ---), se respetan y el índice se coloca después.
  • Si el documento ya tenía un índice generado antes, se reemplaza en su lugar en vez de duplicarlo; podés volver a generarlo cada vez que cambies los títulos.

Preguntas frecuentes

¿Cómo se anidan los niveles?

Cada nivel de encabezado se sangra respecto del más alto que haya en el documento.

¿Funciona en cualquier visor de Markdown?

Los enlaces son correctos para GitHub, GitLab y visores con esa convención; otros programas pueden calcular las anclas de otra forma.

¿Qué pasa si no hay encabezados?

Aparece un aviso indicando que no se encontró ninguno. Si el cuadro está vacío, se pide escribir o subir un Markdown primero.

¿Se modifica mi archivo?

No, el resultado es un texto nuevo; el original no cambia.
