Cómo rotar las páginas de un PDF

Un PDF escaneado de costado o con páginas al revés se arregla girándolo. Esta herramienta rota todas las páginas del documento en 90, 180 o 270 grados y entrega un PDF nuevo. Antes de generarlo muestra una miniatura de la primera página para que veas cómo quedaría.

Paso a paso

  1. Arrastrá tu PDF a la zona o hacé clic para elegirlo. Aparece una miniatura con el nombre y la cantidad de páginas.
  2. En «Girar» elegí la opción: «90° (sentido horario)», «180°» o «270° (sentido horario) / 90° antihorario». La miniatura se actualiza con la etiqueta «así quedaría».
  3. Hacé clic en «Rotar PDF».
  4. Descargá el resultado con «Descargar PDF rotado» (documento-rotado.pdf).

Consejos

  • La rotación se suma a la que ya tuviera cada página: si una página ya estaba girada, el giro se aplica sobre su orientación actual.
  • Se giran todas las páginas a la vez. Si solo una parte del documento está mal, esta herramienta no lo resuelve; primero separá esas páginas con «Dividir PDF», rotalas y después unílas de nuevo con «Unir PDF, imágenes y documentos».
  • Para girar a la izquierda un cuarto de vuelta, elegí 270°.
  • El giro no vuelve a dibujar las páginas: el contenido y el texto del PDF se conservan tal cual.

Preguntas frecuentes

¿La miniatura muestra todas las páginas?

No, dibuja solo la primera página, con la rotación elegida.

¿Funciona con PDF protegidos?

No: un PDF cifrado (con contraseña o con restricciones) no se puede rotar, aparece un aviso y no se descarga nada; desbloqueálo antes con «Desbloquear PDF».

¿Puedo rotar varios PDF juntos?

No, uno por vez.

¿Cambia el tamaño del archivo?

Prácticamente no, porque solo se modifica la orientación de cada página.
