Unir Excel / CSV

Elegí varios archivos de planilla (.xlsx, .xlsm, .xlsb, .xls, .ods) o .csv. Cada hoja de cada archivo se agrega como una hoja separada dentro de un mismo Excel (si un archivo tiene varias hojas, se conservan todas). Se conservan los datos, fórmulas, anchos de columna y celdas combinadas — no se conservan estilos de celda (colores, negrita), imágenes ni gráficos incrustados.
