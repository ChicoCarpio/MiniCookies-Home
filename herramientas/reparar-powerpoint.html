Reparar PowerPoint

Elegí un archivo de PowerPoint (.pptx, .ppt u .odp) que no abre bien. Si alguna diapositiva individual está corrupta, se descarta esa sola — el resto de la presentación se conserva.

📽️ Arrastrá tu archivo de PowerPoint (.pptx, .ppt u .odp) acá o hacé clic para elegirlo
    Solo se descartan las diapositivas cuyo XML está dañado; el resto se copia tal cual, así que las animaciones y transiciones de las diapositivas que quedan se conservan. Si una diapositiva que queda enlazaba a una descartada, el enlace se borra y el texto queda.

    Limitaciones

    • Se quitan las diapositivas dañadas que no se pueden interpretar; el resto del archivo queda intacto.
    • Si el archivo en sí está dañado (no solo una diapositiva puntual), no hay forma de repararlo con esta técnica — se avisa en vez de intentar algo que no va a funcionar.

    Cómo reparar una presentación de PowerPoint dañada

    Cuando una presentación .pptx no abre o PowerPoint ofrece «repararla» y falla, muchas veces el problema está en una o dos diapositivas con el XML interno dañado. Esta herramienta revisa una por una las diapositivas, descarta solo las que no se pueden interpretar y conserva el resto tal cual. Recibe un archivo .pptx y devuelve otro .pptx con las diapositivas sanas, sin tocar sus animaciones ni transiciones. Si subís un .ppt o un .odp, se acepta pero el resultado se guarda como .pptx.

    Paso a paso

    1. Arrastrá tu archivo a la zona «Arrastrá tu archivo de PowerPoint (.pptx, .ppt u .odp) acá o hacé clic para elegirlo».
    2. Hacé clic en «Reparar». El botón pasa a «Reparando...» mientras se revisan las diapositivas.
    3. Fijate en el mensaje: puede decir que se leyó la presentación completa sin descartar nada, o cuántas diapositivas se descartaron de un total.
    4. Descargá el resultado con «Descargar PowerPoint reparado» (presentacion-reparada.pptx).

    Consejos

    • Conviene guardar el original aparte: las diapositivas descartadas no se pueden recuperar del archivo nuevo.
    • Si una diapositiva que se conserva tenía un enlace hacia una que se descartó, el enlace se borra pero el texto queda. Revisalo al abrir el resultado.
    • También se sacan de las secciones y de las presentaciones personalizadas las diapositivas eliminadas, para que PowerPoint no vuelva a pedir reparación.
    • El botón «?» junto a «Reparar» resume qué se descarta y qué se conserva.

    Preguntas frecuentes

    ¿Qué se considera una diapositiva dañada?

    Aquella cuyo XML no se puede leer o cuyo archivo falta dentro del paquete.

    ¿Qué pasa si el daño es del archivo completo?

    Si falta la estructura mínima de un .pptx, o está dañado el archivo principal de la presentación (presentation.xml), se muestra un error y no se intenta nada más.

    ¿Y si todas las diapositivas están rotas?

    Se avisa que el archivo está demasiado dañado y no se genera nada.

    ¿Funciona con .ppt viejos?

    Sí, acepta .ppt y .odp además de .pptx. El resultado se guarda siempre como .pptx.
