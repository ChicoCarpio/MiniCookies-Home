      Cómo convertir un EPUB a Markdown y un Markdown a EPUB

      Convierte un libro EPUB sin protección a un archivo Markdown (.md), o un archivo Markdown a un libro EPUB. Es útil para llevar un libro a un editor de notas como Obsidian, para editar su texto en un formato liviano o para publicar un texto escrito en Markdown como libro electrónico. Entra un .epub o un .md/.markdown y sale un .md o un .epub.

      Paso a paso

      1. Arriba elegí la dirección: «EPUB → Markdown» o «Markdown → EPUB».
      2. En EPUB → Markdown, arrastrá uno o varios archivos .epub (o hacé clic para elegirlos) y tocá «Convertir a Markdown».
      3. Con un solo libro se muestra el texto resultante: podés usar «Copiar Markdown» o «Descargar .md» (se guarda como libro.md). Con varios libros se baja un .zip llamado markdown-desde-epub.zip con un .md por libro.
      4. En Markdown → EPUB, cargá el archivo .md; el campo «Título del libro» se completa con el nombre del archivo y podés cambiarlo. Si querés, escribí el «Autor (opcional)».
      5. Tocá «Convertir a EPUB» y después «Descargar EPUB». El archivo se llama como el título que pusiste.

      Consejos

      • Al pasar de EPUB a Markdown, cada capítulo queda separado por una línea horizontal (---); las tablas se convierten en tablas de Markdown.
      • Al pasar de Markdown a EPUB, cada título de primer nivel (#) abre un capítulo nuevo. Si tu texto no tiene #, queda como un solo capítulo.
      • Las imágenes del libro van dentro del Markdown, codificadas en texto (base64), y no como archivos aparte. Por eso el .md puede pesar bastante más que el EPUB: cada imagen ocupa cerca de un tercio más.
      • No funciona con EPUB que tienen DRM (candado editorial).

      Preguntas frecuentes

      ¿Puedo convertir varios EPUB juntos?

      Sí, en la dirección EPUB → Markdown. Recibís un .zip con un .md por libro.

      ¿Qué pasa con el HTML dentro de mi Markdown?

      Antes de armar el EPUB el contenido pasa por una limpieza de HTML, así que lo peligroso (scripts, por ejemplo) se elimina.

      ¿Se conserva el formato?

      Títulos, listas, negritas, cursivas, enlaces y tablas, en la medida en que Markdown las admite.

      ¿Funciona con un EPUB comprado en una tienda?

      Solo si no tiene DRM.
