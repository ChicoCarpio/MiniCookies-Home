Cómo extraer páginas de un PDF

Saca solo las páginas que te interesan de un PDF y las guarda en un archivo nuevo, sin tocar el original. Sirve para mandar únicamente un capítulo, separar una factura de un lote o quedarte con las páginas firmadas de un contrato. Podés elegir las páginas con clics sobre las miniaturas o escribiendo un rango. Entra un PDF; sale un PDF nuevo.

Paso a paso

  1. Arrastrá tu PDF o hacé clic para elegirlo. Se generan las miniaturas de todas las páginas.
  2. Hacé clic en las miniaturas que querés conservar (se marcan con un borde) o escribí en «Páginas a extraer» un rango como 1-3,5,8-9. Las dos formas se sincronizan solas.
  3. Si necesitás ver una página mejor, tocá la lupa de la esquina de su miniatura para abrirla en grande.
  4. Tocá «Extraer páginas» y después «Descargar PDF extraído» (se guarda como «paginas-extraidas.pdf»).

Consejos

  • El orden en que escribís las páginas es el orden del PDF nuevo: 5,1 pone la página 5 antes que la 1, y un rango al revés como 5-2 las deja en orden descendente.
  • Se pueden repetir páginas (por ejemplo 1,1,2) si necesitás duplicarlas.
  • Si una página está fuera de rango, la herramienta dice cuál trozo falló y cuántas páginas tiene el PDF; si el texto no se entiende, solo dice cuál trozo no entendió.
  • Para PDF muy largos, las miniaturas tardan unos segundos en generarse.

Preguntas frecuentes

¿Se modifica mi PDF original?

No, se crea uno nuevo.

¿Puedo elegir con clics y con texto a la vez?

Sí; al escribir en el campo se actualizan las miniaturas marcadas, y al hacer clic en una miniatura se actualiza el texto.

¿Se conservan los enlaces, formularios y marcadores?

La herramienta copia las páginas con PDF-lib, y algunos elementos pueden no conservarse.
