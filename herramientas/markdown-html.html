Espacio publicitario

Cómo convertir entre Markdown y HTML

Esta herramienta pasa texto de Markdown a HTML y de HTML a Markdown en la misma página. Sirve cuando escribís en Markdown (notas, un README, un borrador de blog) y necesitás el código HTML para pegarlo en una web, o cuando tenés una página o un fragmento HTML y lo querés limpio en Markdown. Podés escribir o pegar el texto en el cuadro, o abrir un archivo; el resultado se actualiza mientras tipeás.

Paso a paso

  1. Elegí la dirección arriba: «Markdown → HTML» o «HTML → Markdown».
  2. Escribí o pegá tu texto en el cuadro de la izquierda, o tocá «Abrir archivo» para cargar un .md, .markdown, .txt, .html o .htm. Si el archivo es de la otra dirección, la herramienta cambia sola.
  3. En Markdown → HTML, mirá la «Vista previa» a la derecha. Con «Ver código HTML» se despliega el código (otro clic sobre el mismo botón lo oculta) y con «Copiar código HTML» se copia al portapapeles.
  4. En HTML → Markdown, el resultado aparece en el cuadro de la derecha: usá «Copiar Markdown» o «Descargar .md».
  5. En Markdown → HTML, «Descargar .html» baja una página completa (con <html>, <head> y <body>) que podés abrir directo en el navegador.

Consejos

  • Al cambiar de dirección, el cuadro de entrada vuelve a mostrar un texto de ejemplo, así que copiá antes lo que no quieras perder.
  • El título de la página descargada se toma del primer encabezado del texto; si no hay ninguno, usa el nombre del archivo abierto o «Documento».
  • El HTML → Markdown deja los títulos con almohadillas (#, ##…), los bloques de código entre tres acentos graves (```) y las tablas como tablas de Markdown.
  • Si tu archivo .md trae HTML crudo, la vista previa lo limpia por seguridad, pero el código que copiás o descargás queda tal como lo generó el conversor.

Preguntas frecuentes

¿Puedo convertir varios archivos a la vez?

No, trabaja con un texto o un archivo por vez.

¿Se ve igual que en GitHub o en mi editor?

La vista previa usa el conversor propio del sitio: sigue CommonMark y las extensiones de GitHub para tablas, tachado, listas de tareas y enlaces automáticos. Los estilos dependen de la página donde pegues el HTML.

¿Qué pasa con las imágenes?

En Markdown → HTML se generan las etiquetas <img> con la dirección que escribiste. No se incrustan ni se descargan.

¿Funciona con HTML de una página completa?

Sí, podés pegarlo o abrirlo; conviene revisar el resultado, porque menús o scripts de la página también se convierten en texto.
