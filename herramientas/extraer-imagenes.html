Cómo extraer las imágenes de un PDF

Recorre un PDF y guarda en un .zip las imágenes que lleva embebidas (fotos, logos, ilustraciones). No convierte las páginas en imágenes: para eso está PDF ↔ Imágenes. Es útil para recuperar la foto de un informe o el logo de un documento sin hacer capturas de pantalla. Entra un PDF; sale un .zip con archivos PNG.

Paso a paso

  1. Arrastrá tu PDF o hacé clic para elegirlo. Aparece una miniatura con su nombre y la cantidad de páginas.
  2. Tocá «Extraer imágenes». Se muestra el avance («Revisando página 3 de 12...»).
  3. Cuando termina, aparece «Listo, se encontraron N imagen(es)» y el enlace «Descargar .zip».
  4. Descomprimí el .zip: cada imagen se llama pagina-X-imagen-N.png, donde X es la página donde se encontró.

Consejos

  • Si la misma imagen aparece en varias páginas (un logo repetido), se guarda una sola vez.
  • Las imágenes salen en PNG, aunque en el PDF estuvieran en otro formato.
  • Si el PDF es todo texto o dibujos vectoriales (gráficos), no hay imágenes para extraer y la herramienta lo avisa.
  • Un PDF escaneado suele tener una imagen por página, así que obtendrás las páginas como fotos; para convertir páginas a imagen directamente, mirá PDF ↔ Imágenes.

Preguntas frecuentes

¿Por qué dice que no encontró imágenes si veo dibujos en el PDF?

Los dibujos vectoriales (gráficos, logos dibujados con trazos) no son imágenes embebidas, y algunas imágenes usan formatos que la herramienta no puede leer.

¿Se conserva la calidad original?

Se extrae la imagen con su resolución propia y se guarda como PNG; no se redimensiona.

¿Puedo cargar varios PDF?

No, un PDF por vez.
