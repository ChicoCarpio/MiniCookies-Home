    Limitaciones

    Si el documento no tiene ningún Título 1, se trata como una sola sección (no hay nada para reordenar). Se conservan títulos, negrita, cursiva, listas, tablas e imágenes de cada sección.

    Cómo reordenar las secciones de un documento de Word

    Divide un documento de Word (.docx) en secciones, tomando como corte cada párrafo con estilo Título 1, y te deja reordenarlas o quitar las que no querés. Es útil para reorganizar capítulos de un informe, una tesis o un manual. Entra un .docx y sale un .docx nuevo con las secciones en el orden elegido, separadas por saltos de página.

    Paso a paso

    1. Arrastrá el documento .docx a la zona de carga o hacé clic para elegirlo.
    2. Aparece una fila por sección con el texto del Título 1 correspondiente.
    3. Arrastrá las filas para reordenarlas o tocá la ✕ para quitar una sección.
    4. Tocá «Descargar reordenado» y luego «Descargar Word». El archivo se llama «documento-reordenado.docx».

    Consejos

    • Para que funcione, el documento tiene que usar el estilo «Título 1» de Word en los encabezados de sección. Si no hay ningún Título 1, se trata como una sola sección y no hay nada para reordenar (lo aclara la página en «Limitaciones»).
    • Se conservan títulos, negrita, cursiva, listas, tablas e imágenes de cada sección.
    • El documento resultante se reconstruye: es un archivo nuevo que contiene el texto y esos elementos, así que revisá el aspecto final antes de entregarlo.
    • Cada sección empieza en una página nueva en el resultado.

    Preguntas frecuentes

    ¿Puedo reordenar subtítulos (Título 2)?

    No, solo se corta en Título 1; los demás niveles viajan dentro de su sección.

    ¿Se conservan encabezados y pies de página, fuentes y colores originales?

    La página lista como conservados títulos, negrita, cursiva, listas, tablas e imágenes. Otros elementos, como encabezados, pies de página y estilos particulares, pueden no mantenerse.

    ¿Funciona con .doc antiguos?

    No, solo .docx.

    ¿Qué pasa si el documento tiene texto antes del primer Título 1?

    La herramienta lo trata como una sección más; el nombre que se le muestra se toma del documento o de un título por defecto, «Documento».
