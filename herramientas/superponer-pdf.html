Cómo superponer un PDF sobre otro

Pensada para poner un membrete, una plantilla, una marca de agua o un fondo en un documento ya terminado. Tomás un PDF base (el contenido) y otro PDF de superposición, y cada página del primero recibe encima la página correspondiente del segundo. Devuelve un único PDF con el resultado combinado.

Paso a paso

  1. En «PDF base (el contenido)» arrastrá o elegí el documento al que querés agregarle algo.
  2. En «PDF de superposición (la plantilla/membrete)» elegí el PDF que va a quedar encima.
  3. Hacé clic en «Superponer PDFs» cuando ambos tengan miniatura; el botón se habilita recién con los dos archivos cargados.
  4. Descargá el resultado con «Descargar PDF resultante» (documento-superpuesto.pdf).

Consejos

  • La página 1 del PDF base recibe la página 1 de la superposición, la 2 la 2, y así. Si la superposición tiene menos páginas, se repite la última en el resto.
  • Una plantilla de una sola página con fondo transparente es lo más práctico para un membrete que se repite en todo el documento.
  • La superposición se dibuja encima del contenido y se ajusta al tamaño de cada página base. Si tu membrete tiene áreas opacas, va a tapar lo que esté debajo; usá una plantilla con zonas vacías o transparentes.
  • Cuidá la proporción: si la superposición tiene otro tamaño o relación de aspecto que la página base, se estira para cubrirla.

Preguntas frecuentes

¿Cuál es el archivo base y cuál el de superposición?

El base es el contenido que querés conservar al fondo; el de superposición es la plantilla que se pone arriba.

¿Puedo usar páginas distintas de la plantilla para cada hoja?

Sí, si la plantilla tiene varias páginas, cada hoja recibe la que le corresponde por número.

¿Puedo mover o escalar la superposición?

No, no hay opciones de posición ni de tamaño; siempre cubre la página completa.

¿Modifica los archivos originales?

No, se genera un PDF nuevo.
