    Espacio publicitario

    Cómo hacer buscable un PDF escaneado

    Un escaneo es una foto de la página: se ve el texto, pero la computadora no lo sabe leer, así que no se puede buscar ni copiar. Este flujo reconoce el texto con OCR, lo deja invisible encima de cada página y después recomprime las imágenes para que el archivo no pese de más.

    Paso a paso

    1. Arrastrá los PDF escaneados o las fotos de las páginas a la zona.
    2. Elegí el «Idioma del texto»: el reconocimiento acierta mucho más cuando sabe en qué idioma está escrito.
    3. Pulsá «Ejecutar el flujo». Cada página se endereza si está torcida, se reconoce su texto y el PDF se arma igual al original.
    4. Descargá el resultado: un PDF por archivo, o un .zip si cargaste varios.

    Consejos

    • Si el escaneo es pálido o tiene manchas, probá «Preparar la imagen: Blanco y negro puro»; para papeles limpios, «Contraste automático» suele bastar.
    • El texto reconocido queda invisible: el PDF se ve igual que antes, pero ahora Ctrl+F encuentra las palabras.
    • «Comprimir PDF» solo cambia las fotos de cada página; si el archivo no baja de peso, queda el que salió del OCR.

    Preguntas frecuentes

    ¿Sirve para un PDF que ya tiene texto?

    Funciona, pero no hace falta: si el PDF se puede buscar, el texto ya está. Para sacarlo a un .txt usá «PDF ↔ Texto».

    ¿Por qué tarda más que otros flujos?

    Reconocer texto es el trabajo más pesado del sitio. El flujo abre varios motores de reconocimiento a la vez para usar más núcleos, pero un PDF de muchas páginas igual lleva su tiempo.

    ¿Reconoce letra manuscrita?

    Muy poco. El reconocimiento está pensado para texto impreso; la letra a mano suele salir con muchos errores.
