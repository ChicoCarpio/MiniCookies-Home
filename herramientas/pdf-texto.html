    Cómo pasar texto de un PDF a .txt y al revés

    Extraer el texto de un PDF sirve para copiar un párrafo sin los saltos de línea raros, buscarlo en otro programa o reutilizarlo en un correo. En sentido contrario, un archivo .txt se convierte en un PDF para compartirlo con formato fijo. Elegí el sentido con el selector de arriba.

    Paso a paso

    1. PDF → Texto: arrastrá uno o varios PDF y pulsá «Extraer texto».
    2. Con un solo PDF aparece el texto en un cuadro: usá «Copiar texto» o «Descargar .txt». Entre una página y la siguiente se inserta una línea separadora.
    3. Con varios PDF no se muestra el texto: se descarga un .zip con un .txt por cada PDF y un resumen de cuáles se pudieron procesar.
    4. Texto → PDF: elegí «Texto → PDF», cargá un archivo .txt, pulsá «Convertir a PDF» y descargá el resultado, que lleva el mismo nombre que el .txt.

    Consejos

    • Si sale el aviso de que no se encontró texto, el PDF es un escaneo (una foto por página): el texto no está guardado como texto. Usá la herramienta de OCR de PDF escaneado que enlaza el mismo aviso.
    • El PDF generado desde un .txt es sencillo: páginas A4, letra Helvetica de 11 puntos y líneas ajustadas al ancho. Sirve para texto plano, no para diseños.
    • Los caracteres que esa letra no incluye (emojis, ideogramas) no se pueden dibujar y se reemplazan por otro símbolo.

    Preguntas frecuentes

    ¿Se conserva el formato del PDF al extraer el texto?

    No, se obtiene texto plano: sin negritas, colores ni imágenes. Es lo que la hace útil para copiar y pegar.

    ¿Puedo convertir varios archivos .txt a PDF a la vez?

    No, el sentido Texto → PDF trabaja con un archivo por vez. Para extraer texto de PDF sí podés elegir varios.

    ¿Qué es la línea entre páginas del texto extraído?

    Es un separador de página que marca dónde terminaba cada una en el PDF. Podés borrarlo con buscar y reemplazar si no lo querés.
