Cómo formatear y validar un JSON

Cuando un JSON llega todo en una línea, o la aplicación se queja de que «hay un error en algún lado», leerlo a ojo es una pérdida de tiempo. Esta herramienta toma el texto que pegues, lo revisa con el analizador del navegador y te devuelve una versión con sangría legible o una versión compacta de una sola línea. Si el JSON está roto, te dice qué falló y en qué línea y columna, y deja marcado el carácter problemático en la caja de entrada.

Paso a paso

  1. Pegá tu JSON en la caja grande de arriba.
  2. Tocá «Formatear (indentado)» para obtener el texto con sangría de 2 espacios, o «Minificar» para quitar espacios y saltos de línea.
  3. Si es válido, aparece «JSON válido» y el resultado se muestra en la caja de abajo; si no, verás el mensaje de error con la línea y la columna.
  4. Usá «Copiar resultado» para llevarlo al portapapeles o «Descargar .json» para guardarlo como archivo.

Consejos

  • Si el JSON es inválido, la caja de entrada se marca en rojo y el cursor queda sobre el punto del error: corregilo ahí y volvé a tocar el botón.
  • Los errores más comunes son una coma sobrante después del último elemento, comillas simples en lugar de dobles y claves sin comillas.
  • «Descargar .json» también sirve como atajo: si todavía no formateaste nada, formatea primero y descarga el resultado. El archivo se llama json-formateado seguido de la fecha.
  • Minificar es útil para pegar un JSON en un campo de una sola línea, o para reducir su tamaño antes de enviarlo.

Preguntas frecuentes

¿Puede arreglar un JSON roto?

No. Solo lo valida y te señala dónde está el error; la corrección la hacés vos.

¿Cambia el orden de las claves o los valores?

No, se conserva el orden. Lo único que cambia es el espaciado.

¿Acepta comentarios o comillas simples?

No, solo JSON estándar. Los comentarios y las comillas simples se reportan como error.

¿Qué sangría usa?

Siempre 2 espacios; no hay opción para cambiarla.
