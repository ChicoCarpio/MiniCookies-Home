      Cómo convertir entre Markdown y Word

      Convierte Markdown en un documento Word (.docx) editable, y un documento Word en Markdown. Sirve para pasar apuntes o borradores escritos en Markdown a un formato que cualquiera pueda abrir y corregir en Word, o para sacar el texto de un .docx hacia un editor de notas, un sitio estático o un repositorio. Acepta archivos sueltos o varios a la vez, y también permite escribir el Markdown a mano.

      Paso a paso

      1. Elegí «Markdown → Word» o «Word → Markdown».
      2. En Markdown → Word, arrastrá uno o varios archivos .md (también acepta .markdown y .txt) y tocá «Convertir a Word». Con un archivo baja un .docx; con varios, un .zip con un .docx por archivo.
      3. Si preferís escribir, usá la sección «O escribilo a mano»: hay un cuadro con vista previa, un campo «Nombre del archivo» y el botón «Descargar .docx».
      4. En Word → Markdown, arrastrá uno o varios .docx y tocá «Convertir a Markdown». Con un solo documento ves el texto, podés usar «Copiar Markdown» y descargarlo.
      5. Si el Word tenía imágenes, la descarga es un .zip con el .md y una carpeta de imágenes; con varios documentos también es un .zip.

      Consejos

      • En Markdown → Word se conservan títulos, negrita, cursiva, listas, tablas e imágenes; los enlaces quedan como texto y los bloques de código como texto plano.
      • En Word → Markdown se conservan además cuadros de texto y notas al pie (van al final, numeradas). No pasan los encabezados y pies de página, los comentarios ni el texto de SmartArt y gráficos.
      • Markdown no tiene celdas combinadas: una celda que abarcaba varias columnas deja vacías las vecinas, y una tabla dentro de otra se convierte en texto. El botón «?» junto a «Convertir a Markdown» resume estas limitaciones.
      • Si aparece una advertencia al leer el documento, revisá el resultado: puede haber elementos que no se transfirieron perfectamente.

      Preguntas frecuentes

      ¿Acepta archivos .doc antiguos?

      No, solo .docx.

      ¿Las imágenes se incluyen en el Markdown?

      Se guardan como archivos en una carpeta <documento>-imagenes y el Markdown las enlaza; por eso la descarga es un .zip.

      ¿Puedo cambiar el estilo del Word generado?

      No hay opciones de estilo; el documento sale con el formato por defecto de los títulos y párrafos.

      ¿Se pueden convertir muchos archivos de una vez?

      Sí, se arrastran varios y se descarga un único .zip.
