Excel / CSV a PDF

Elegí un archivo y lo convertimos en una tabla PDF, lista para imprimir o compartir. Las columnas y filas completamente vacías se omiten, y se conserva negrita, cursiva, subrayado y color de texto de las celdas cuando el archivo los tiene (no se replican fuentes personalizadas, bordes ni tamaños de letra por celda). Si el archivo tiene gráficos, se agregan como páginas extra después de la tabla, reconstruidos a partir de sus datos — el estilo puede no ser idéntico al del original. No se incluyen imágenes embebidas.

📊 Arrastrá tu archivo acá o hacé clic para elegirlo (.xlsx, .xlsm, .xlsb, .xls, .ods o .csv)

    Arrastrá sobre la cuadrícula para marcar un rectángulo o escribí una dirección (por ejemplo, A1:D8). Podés agregar varios rangos.
