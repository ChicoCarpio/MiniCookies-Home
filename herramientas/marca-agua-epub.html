    Cómo agregar un texto a cada capítulo de un EPUB

    Agrega una línea de texto, como un aviso de copyright, «muestra gratuita» o tu nombre, al principio o al final de cada capítulo de un libro EPUB. Se inserta dentro del libro original sin rehacerlo, así que se conservan estilos, fuentes, portada y metadatos. No es una marca de agua diagonal: es una línea de texto visible en cada capítulo.

    Paso a paso

    1. Arrastrá tu archivo .epub a la zona de carga o hacé clic para elegirlo.
    2. Escribí el «Texto a agregar» (por ejemplo «© 2026 Mi nombre — muestra gratuita»).
    3. En «Posición» elegí «Al principio de cada capítulo» o «Al final de cada capítulo».
    4. Tocá «Aplicar y descargar» y después «Descargar EPUB». El archivo se llama «libro-con-texto.epub».

    Consejos

    • El texto se agrega como un párrafo en cursiva, de color gris y letra un poco más chica que el resto, para que se note sin molestar la lectura.
    • Se pone una vez por capítulo; si querés solo un aviso en la portada o al final del libro, conviene revisar el resultado en tu lector.
    • Es útil para repartir una muestra gratuita con el aviso en todos los capítulos, o para anotar la versión de un borrador.
    • Si dejás el texto vacío, aparece el aviso «Escribí el texto que querés agregar».

    Preguntas frecuentes

    ¿Modifica mi archivo original?

    No, genera una copia nueva; el original queda intacto.

    ¿Sirve como protección contra la copia?

    No, es solo un texto visible; cualquiera con un editor de EPUB puede quitarlo.

    ¿Puedo cambiar el color o el tamaño del texto?

    No, el estilo es fijo.

    ¿Qué es un capítulo para la herramienta?

    Cada archivo de contenido del libro.
