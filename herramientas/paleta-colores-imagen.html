Esquemas de color

Color base
Cada esquema gira el tono del color base en el círculo cromático y conserva su saturación y su luminosidad. Complementario: el color opuesto (180°). Análogos: los vecinos (±30°). Triádico: tres colores a 120°. Complementario dividido: los dos vecinos del opuesto (150° y 210°). Tetrádico: cuatro colores a 90°.
Espacio publicitario

Cómo extraer la paleta de colores de una imagen

Analiza una imagen y te muestra sus colores dominantes con el código hexadecimal, listos para copiar. Es útil para diseñadores, para armar una presentación o una web con los colores de una foto o de un logo, o para sacar el color exacto de un punto concreto de la imagen. Además arma esquemas de color (complementario, análogos y otros) a partir del color que elijas como base.

Paso a paso

  1. Arrastrá una imagen o hacé clic para elegirla. Aparece la vista previa y la paleta de colores dominantes, cada uno con su código y el porcentaje de la imagen que ocupa.
  2. Con el deslizador «Cantidad de colores» ajustá cuántos colores querés, entre 4 y 16 (empieza en 8).
  3. Tocá un color de la paleta para copiar su código al portapapeles; ese color pasa a ser el «Color base». También podés tocar la imagen para tomar el color de ese punto con el cuentagotas.
  4. En «Esquemas de color» elegí en «Esquema»: Complementario, Análogos, Triádico, Complementario dividido o Tetrádico.
  5. Descargá el resultado con «Descargar paleta (.png)» o «Descargar códigos (.txt)».

Consejos

  • El botón «?» junto al esquema explica los ángulos: complementario a 180°, análogos a ±30°, triádico a 120°, complementario dividido a 150° y 210°, tetrádico a 90°. Se conservan la saturación y la luminosidad del color base.
  • Para que el análisis sea rápido, la imagen se reduce internamente; los colores promedio de cada zona no cambian por eso.
  • Los píxeles transparentes se ignoran, tanto en la paleta como con el cuentagotas.
  • El .txt trae un color por línea con el código hexadecimal, el valor RGB y el porcentaje, más el esquema elegido; el .png es una tarjeta por color.

Preguntas frecuentes

¿Por qué mis colores salen agrupados y no son exactos?

Los tonos parecidos se juntan en un mismo grupo y se muestra el promedio real de sus píxeles.

¿Puedo usar el color de un punto exacto?

Sí, tocando la imagen con el cuentagotas; aparece como color base.

¿Cómo se llaman los archivos descargados?

<nombre-de-la-imagen>-paleta.png y <nombre-de-la-imagen>-paleta.txt.

¿Qué formatos de imagen acepta?

Cualquiera que tu navegador pueda abrir, como JPG, PNG, WebP o GIF.
