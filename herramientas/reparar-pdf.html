Limitaciones El nivel 1 vuelve a escribir el PDF y conserva el texto y la calidad originales, pero lo que está tan dañado que no se puede leer no llega al resultado. El nivel 2 convierte cada página en imagen: se pierde el texto seleccionable y copiable, y también los enlaces, formularios, marcadores y adjuntos.

Si el archivo está muy dañado, a veces solo se puede recuperar el contenido visual de cada página como imagen — en ese caso se pierde el texto seleccionable/copiable. Si ni así se puede recuperar, el archivo está dañado más allá de lo que se puede arreglar desde el navegador.

Cómo reparar un PDF dañado

A veces un PDF no abre porque la descarga se cortó, se copió mal o quedó con la estructura interna rota, aunque las páginas sigan ahí adentro. Esta herramienta recibe ese archivo y prueba rescatarlo en dos niveles, del menos al más invasivo. Primero intenta reescribir el PDF limpio, conservando texto y calidad. Si eso falla o pierde páginas, reconstruye cada página como imagen. Devuelve un PDF nuevo para descargar, junto con un aviso de cuántas páginas se pudieron recuperar.

Paso a paso

  1. Arrastrá el PDF dañado a la zona «Arrastrá tu PDF dañado acá o hacé clic para elegirlo», o hacé clic para buscarlo. Si no se puede previsualizar, aparece marcado con una advertencia, pero igual podés seguir.
  2. Hacé clic en «Intentar reparar». Vas a ver el progreso: «Probando nivel 1» y, si hace falta, «Reconstruyendo página X de Y».
  3. Leé el mensaje del resultado: dice si se reparó con el nivel 1 o solo con el nivel 2, y cuántas páginas se recuperaron del total.
  4. Descargá el archivo con «Descargar PDF reparado» (se llama documento-reparado.pdf).

Consejos

  • Si el mensaje dice que se usó el nivel 2, el resultado son imágenes de cada página: ya no vas a poder seleccionar ni copiar texto, y se pierden enlaces, formularios, marcadores y adjuntos. Si necesitás volver a tener texto, pasalo después por «OCR de PDF e imágenes escaneadas».
  • Compará siempre «Páginas recuperadas: X de Y» con lo que esperabas. Un archivo cortado a la mitad puede devolver solo parte del documento.
  • Los PDF protegidos con contraseña no están dañados, pero esta herramienta no los repara: muestra un aviso y te pide desbloquearlos antes con «Desbloquear PDF».
  • Si el PDF ya abría bien y solo querés achicarlo, usá «Comprimir / optimizar PDF».

Preguntas frecuentes

¿Qué diferencia hay entre el nivel 1 y el nivel 2?

El nivel 1 vuelve a escribir el archivo y mantiene texto y calidad originales. El nivel 2 dibuja cada página y la guarda como imagen JPG, así que suele pesar más y no tiene texto seleccionable.

¿Qué pasa si el PDF está cortado al final?

La herramienta quita el último objeto, que quedó a medias, y agrega un cierre nuevo (el trailer) que apunta al catálogo del documento. Después aplica los dos niveles. Si ese objeto era una página, esa página no vuelve.

¿Siempre logra repararlo?

No. Si alguna página no se puede leer ni reconstruir, aparece el aviso «No se pudo reparar el PDF con ninguno de los dos niveles». En ese caso, el daño es mayor de lo que esta herramienta puede rescatar.

¿Acepta varios archivos a la vez?

No, trabaja con un PDF por vez.
