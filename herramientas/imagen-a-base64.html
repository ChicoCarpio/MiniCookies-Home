Cómo convertir una imagen a Base64

Base64 es una forma de escribir una imagen como texto para incrustarla directamente en HTML, CSS o un correo, sin depender de un archivo aparte. Esta herramienta lee una imagen y te entrega ese texto en formato data URI, con el encabezado correspondiente (data:image/png;base64,...), listo para pegar.

Paso a paso

  1. Arrastrá una imagen a la zona de carga o hacé clic para elegirla.
  2. Revisá la vista previa y comprobá que sea la correcta.
  3. El texto Base64 aparece en la caja de abajo.
  4. Tocá «Copiar Base64» para llevarlo al portapapeles o «Descargar .txt» para guardarlo.

Consejos

  • El resultado incluye el prefijo data: completo, así que podés usarlo directo en <img src="..."> o en background: url(...) de CSS.
  • El texto es cerca de un tercio más grande que la imagen original: conviene usarlo con íconos o imágenes chicas, no con fotos pesadas.
  • Si la imagen es grande, la caja de texto puede ser muy extensa; usar «Copiar Base64» evita seleccionar a mano.
  • El archivo descargado se llama como la imagen original, con el sufijo -base64.txt.

Preguntas frecuentes

¿Qué formatos de imagen acepta?

Cualquier imagen que el navegador reconozca, como PNG, JPG, GIF, WebP o SVG.

¿Se modifica o comprime la imagen?

No, se codifica tal cual; el texto contiene los bytes originales.

¿Puedo convertir de Base64 de vuelta a imagen?

No, esta herramienta solo hace el camino de imagen a texto.

¿Para qué sirve incrustar una imagen así?

Para evitar una petición extra al cargar una página con iconos chicos, o para enviar un HTML autónomo en un solo archivo.
