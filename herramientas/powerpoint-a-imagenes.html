    Límites conocidos

    Como esto corre 100% en tu navegador (no en PowerPoint real), el resultado puede no ser 100% fiel al original — diapositivas con diseños muy complejos, animaciones o elementos poco comunes pueden verse distinto. Si no se puede renderizar ninguna diapositiva, se avisa el error; una diapositiva ilegible sale en blanco y lo que no se sabe dibujar se omite — para el texto de todas formas está Extraer texto de PowerPoint.

    Cómo exportar las diapositivas de PowerPoint como imágenes

    Exporta cada diapositiva de una presentación .pptx como una imagen PNG, agrupadas en un archivo .zip. Sirve para subir diapositivas a un documento o a una red social, armar un resumen visual, compartir una presentación sin enviar el archivo editable, o usar una diapositiva como imagen en otro programa. El dibujo lo hace la propia herramienta en tu navegador, no PowerPoint.

    Paso a paso

    1. Arrastrá tu archivo .pptx o hacé clic para elegirlo.
    2. Tocá «Convertir a imágenes». Mientras trabaja ves el avance («Renderizando diapositivas...») y luego se muestra la vista previa de cada diapositiva.
    3. Cuando termina, tocá «Descargar .zip con las imágenes».
    4. Descomprimí el .zip: cada diapositiva queda como diapositiva-01.png, diapositiva-02.png, etcétera (la cantidad de ceros se ajusta al total).

    Consejos

    • Revisá la vista previa antes de descargar: como el dibujo no lo hace PowerPoint real, las diapositivas con diseños muy complejos, animaciones o elementos poco comunes pueden verse distintas del original.
    • Los PNG no tienen compresión con pérdida, así que el texto y las formas salen nítidos; a cambio, pueden pesar bastante si la diapositiva tiene muchas fotos.
    • Lo que no se puede dibujar se omite, y una diapositiva ilegible sale en blanco. Solo si todas las diapositivas salen vacías la herramienta avisa con un error. Las diapositivas ocultas también se convierten.
    • Si lo único que necesitás es el contenido de texto, usá Extraer texto de PowerPoint.

    Preguntas frecuentes

    ¿Acepta archivos .ppt antiguos?

    No, solo .pptx.

    ¿Puedo elegir qué diapositivas exportar o la resolución?

    No, se exportan todas, sin opciones de tamaño.

    ¿Se pierden las animaciones y transiciones?

    Sí: cada diapositiva es una imagen fija.

    ¿Se exportan las notas del orador?

    No, solo lo que se ve en la diapositiva.
