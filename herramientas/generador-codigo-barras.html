Cómo generar un código de barras

Sirve para crear rápido un código de barras a partir de un número o un texto: una etiqueta de inventario, un código para un producto o una prueba de lector. Escribís el contenido, elegís el formato y obtenés el dibujo al instante, que podés bajar como imagen vectorial SVG, nítida a cualquier tamaño.

Paso a paso

  1. Escribí el contenido en «Texto o número» (viene con un ejemplo cargado).
  2. Elegí el «Formato»: CODE128, EAN-13, UPC o CODE39.
  3. Tocá «Generar» (o apretá Enter) para ver el código.
  4. Usá el enlace «Descargar como SVG» que aparece debajo; el archivo se llama codigo-de-barras.svg.

Consejos

  • CODE128 es el más flexible: acepta letras, números y símbolos, y es la mejor opción si no necesitás un estándar de comercio en particular.
  • EAN-13 y UPC son para productos de venta y solo admiten dígitos con una cantidad exacta. Si el contenido no cumple, aparece un mensaje de error en rojo en lugar del código.
  • CODE39 sirve para etiquetas internas simples con mayúsculas y números.
  • Por ser SVG, lo podés insertar en Word, Illustrator o imprimir en grande sin que se pixele. Si necesitás PNG, abrilo y exportalo desde otro programa.

Preguntas frecuentes

¿Cuántos dígitos necesito para EAN-13 y UPC?

EAN-13 pide 13 dígitos (si escribís 12, se agrega el dígito de control) y UPC pide 12 (con 11 también se agrega). Si el dígito de control no coincide, el generador lo reporta como error.

¿Puedo cambiar el color o el tamaño?

No; el código sale siempre en gris oscuro sobre fondo blanco, con el texto debajo.

¿Genera códigos QR?

No, solo códigos de barras lineales. Para leer un QR existe el Lector de códigos QR y de barras.

¿Sirve para comercializar productos?

El dibujo es válido, pero los números EAN y UPC oficiales los asigna GS1; acá no se registran.
