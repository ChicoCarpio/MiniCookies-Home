    Espacio publicitario

    Cómo extraer las imágenes de un libro de Excel

    Saca las imágenes que están insertadas dentro de un libro de Excel (logos, fotos de productos, capturas) y las entrega juntas en un .zip. Es la forma práctica de recuperar las imágenes de un archivo sin abrir cada una desde el programa. Acepta .xlsx, .xlsm, .xlsb y .ods.

    Paso a paso

    1. Arrastrá el archivo o hacé clic para elegirlo (formatos .xlsx, .xlsm, .xlsb u .ods).
    2. Tocá «Extraer imágenes».
    3. Cuando aparezca «Listo», tocá «Descargar .zip con las imágenes»; el archivo se guarda como «imagenes-excel.zip».
    4. Descomprimí el .zip para ver las imágenes con el nombre que tienen dentro del libro.

    Consejos

    • Los archivos .xls (el formato viejo) no funcionan: abrilo en Excel y guardalo como .xlsx antes de usar la herramienta.
    • Se extraen las imágenes insertadas en las hojas; los gráficos de Excel (barras, líneas) son objetos distintos y no aparecen como imagen.
    • Los formatos EMF y WMF (típicos de capturas pegadas desde otros programas de Office) se incluyen aunque algunos visores no los muestren; podés abrirlos con Office o convertirlos con un programa de imágenes.
    • Las imágenes salen tal como están guardadas, sin recortes.

    Preguntas frecuentes

    ¿Sirve para archivos de LibreOffice?

    Sí, con la extensión .ods se leen las imágenes de su carpeta de imágenes.

    ¿Qué pasa si no tiene imágenes?

    La herramienta avisa que no se encontraron imágenes embebidas en el archivo.

    ¿Se pueden extraer gráficos?

    No como imagen; solo las imágenes insertadas.

    ¿Puedo cargar varios archivos?

    No, uno por vez.
