    Cómo reordenar o quitar secciones de un archivo Markdown

    Divide un archivo Markdown (.md o .markdown) en secciones y te deja reordenarlas o quitar las que no querés. Cada sección empieza en un encabezado de primer nivel (una línea que arranca con «# »). Es útil para reorganizar un manual, unas notas o un README largo sin cortar y pegar a mano. Entra un archivo .md y sale otro .md con las secciones en el nuevo orden.

    Paso a paso

    1. Arrastrá el archivo .md a la zona de carga o hacé clic para elegirlo.
    2. Aparece una fila por sección, con el texto del título. Si el archivo tiene contenido antes del primer encabezado, aparece una fila «Introducción (antes del primer encabezado)».
    3. Arrastrá las filas para reordenarlas o tocá la ✕ para quitar una sección completa.
    4. Tocá «Descargar reordenado» y después el enlace «Descargar .md». El archivo se llama «documento-reordenado.md».

    Consejos

    • Solo se cortan las secciones en los encabezados de primer nivel. Los subtítulos («##», «###») viajan junto con la sección a la que pertenecen.
    • Dentro de un bloque de código (entre ``` o ~~~) una línea que empieza con # no se toma como título, así que los comentarios de Python o Bash no rompen el documento.
    • Si el archivo usa saltos de línea de Windows, el resultado conserva ese estilo.
    • Esta herramienta no tiene deshacer: si quitaste una sección por error, volvé a cargar el archivo. Tu original no se modifica.

    Preguntas frecuentes

    ¿Qué pasa si mi documento no tiene encabezados de primer nivel?

    Se muestra como una sola sección y no hay nada para reordenar.

    ¿Puedo mover una sección a un nivel distinto de encabezado?

    No; solo se cambian de lugar.

    ¿Entiende la codificación del archivo?

    Lee el archivo como texto y respeta su final de línea; si tenés acentos rotos, probá primero con Arreglar codificación de un texto.

    ¿Acepta archivos con extensión distinta de .md?

    Solo .md y .markdown.
