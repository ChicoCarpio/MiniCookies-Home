    Cómo extraer las notas del orador de una presentación

    Saca el texto de las notas del orador de una presentación .pptx, una por diapositiva, y las junta en un solo texto plano. Es útil para pasar el guion de una charla a un documento, para imprimirlo o para revisarlo sin abrir PowerPoint. No saca el contenido visible de las diapositivas: para eso está Extraer texto de PowerPoint. Entra un .pptx; sale texto que podés copiar o descargar como .txt.

    Paso a paso

    1. Arrastrá el archivo .pptx o hacé clic para elegirlo.
    2. Tocá «Extraer notas».
    3. Las notas aparecen en un cuadro de texto, cada bloque encabezado por «--- Notas diapositiva N ---».
    4. Usá «Copiar texto» para llevarlas al portapapeles o «Descargar .txt» para guardarlas como «notas-orador.txt».

    Consejos

    • Si una diapositiva tiene la página de notas pero está vacía, aparece «(sin notas)» debajo de su encabezado.
    • Una diapositiva que nunca tuvo notas no aparece en el resultado, porque PowerPoint no crea la página de notas si no hay nada escrito.
    • El número del encabezado es el del archivo de notas dentro del .pptx; si reordenaste o borraste diapositivas, puede no coincidir con la posición actual de la diapositiva.
    • Si la presentación no tiene ninguna nota, la herramienta avisa «Esta presentación no tiene notas del orador».

    Preguntas frecuentes

    ¿Respeta los saltos de línea de las notas?

    Cada párrafo de la nota sale en una línea; los párrafos vacíos se descartan.

    ¿Se mantiene el formato (negrita, listas)?

    No, el resultado es texto plano.

    ¿Funciona con archivos .ppt?

    No, solo .pptx.

    ¿Puedo cargar varias presentaciones?

    No, una por vez.
