Cómo leer un código QR o de barras

Lee el contenido de códigos QR y de códigos de barras (EAN-13, CODE128, CODE39 y otros) a partir de una imagen, un PDF, un documento de Word, Excel o PowerPoint, un EPUB, o directamente con la cámara. Lee un código por cada página o imagen y lista los de todas las páginas o imágenes del archivo; muestra el texto que contiene cada uno y, si es un enlace web, te deja abrirlo.

Paso a paso

  1. Elegí el modo: «Subir archivo» o «Usar cámara».
  2. En el primer caso, arrastrá un archivo (imagen, PDF, .docx, .xlsx, .pptx o .epub) o hacé clic para elegirlo.
  3. En el modo cámara, permití el acceso y apuntá al código. Si tenés varias cámaras, elegí una en el selector «Cámara». Para terminar, tocá «Detener cámara».
  4. Mirá la lista de resultados: cada uno muestra el formato y, en archivos, de qué página o imagen salió. Usá «Copiar» y, si es un enlace, «Abrir enlace».

Consejos

  • En un PDF se examina cada página; si no se detecta un código chico, se vuelve a intentar con más resolución. En documentos Word, Excel, PowerPoint y EPUB se leen las imágenes incrustadas.
  • Una buena imagen ayuda: con luz pareja, enfocada y sin reflejos, el código se lee mejor.
  • «Abrir enlace» solo aparece si el contenido empieza con http:// o https://. Antes de abrir un enlace de un QR desconocido, pensalo dos veces.
  • Mientras se procesa un archivo grande, se muestra el avance («Leyendo página 3 de 10...»).

Preguntas frecuentes

¿Lee varios códigos en una misma imagen?

No: de cada imagen o página se toma un código. Si el archivo tiene varias páginas o imágenes (un PDF, un documento), se listan los de todas.

¿Funciona con fotos de pantalla o impresas?

Sí, mientras el código se vea con claridad.

¿Hace falta internet?

No para leer; solo para abrir un enlace, si lo hacés.

¿La cámara no arranca, qué hago?

Revisá el permiso del navegador y que ninguna otra aplicación esté usando la cámara.
