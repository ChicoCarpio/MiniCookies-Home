    Limitaciones

    • Si el archivo está muy dañado, a veces solo se puede rescatar el texto sin formato (se pierde negrita, tablas, imágenes, etc., pero se recupera el contenido).
    • Incluso cuando se lee con normalidad, el documento se reconstruye desde cero: se conserva el contenido principal, pero pueden perderse encabezados y pies de página, estilos y otros detalles de formato.
    • Si ni así se puede leer, el archivo está demasiado dañado para esta herramienta.

    Cómo reparar un documento de Word dañado

    Si un documento .docx no abre en Word o aparece el mensaje de contenido ilegible, esta herramienta intenta reconstruirlo. Primero lo lee con un lector tolerante y arma un documento nuevo desde cero; si eso falla, rescata como último recurso el texto crudo del archivo. Recibe un .docx y devuelve otro .docx nuevo, que probablemente abra sin problemas pero con el formato simplificado.

    Paso a paso

    1. Arrastrá el documento a la zona «Arrastrá tu documento .docx acá o hacé clic para elegirlo».
    2. Hacé clic en «Reparar» y esperá a que el botón deje de decir «Reparando...».
    3. Leé el aviso de color: en verde, el documento se pudo leer y se reconstruyó; en naranja, solo se recuperó el texto plano.
    4. Descargá el archivo con «Descargar Word reparado» (documento-reparado.docx).

    Consejos

    • El archivo reparado es una reconstrucción, no una copia exacta: revisá títulos, listas, tablas e imágenes antes de reemplazar el original.
    • Si el aviso indica texto plano, copiá el contenido a una plantilla propia y volvé a aplicar el formato.
    • Conservá siempre el archivo original: la herramienta nunca lo modifica, pero el reparado puede perder detalles.
    • Limitación importante: el primer nivel reconstruye el documento (lo lee con mammoth, lo pasa a HTML y lo vuelve a escribir como .docx), así que se pueden perder encabezados, pies de página y estilos.
    • Sirve también para documentos que Word marca como dañados tras una descarga interrumpida, siempre que el interior del archivo siga siendo un .docx legible.

    Preguntas frecuentes

    ¿Qué pierdo en el modo de texto plano?

    Negrita, tablas, imágenes y cualquier formato; se recupera solo el contenido escrito.

    ¿Qué hago si da error?

    El mensaje puede decir que falta la estructura mínima de un .docx o que no se encontró texto legible. En ese caso el archivo está demasiado dañado para esta herramienta.

    ¿Acepta archivos .doc antiguos?

    No, solo .docx.

    ¿Puedo reparar varios a la vez?

    No, se trabaja con un documento por vez.
