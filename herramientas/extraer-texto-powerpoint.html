    Cómo extraer el texto de una presentación de PowerPoint

    Saca todo el texto de una presentación .pptx y lo entrega como texto plano, organizado diapositiva por diapositiva. Sirve para obtener el contenido de una presentación sin tener PowerPoint, para buscar una frase en todo el archivo o para pegarlo en un documento. Entra un .pptx; sale texto que podés copiar o descargar como .txt.

    Paso a paso

    1. Arrastrá la presentación .pptx o hacé clic para elegirla.
    2. Tocá «Extraer texto».
    3. El texto aparece en un cuadro; cada diapositiva comienza con un encabezado «--- Diapositiva N ---».
    4. Usá «Copiar texto» o «Descargar .txt» (se guarda como «texto-presentacion.txt»).

    Consejos

    • Las diapositivas sin texto aparecen igual, con la indicación «(sin texto)», así que la numeración siempre coincide con el orden de las diapositivas.
    • Las tablas salen con sus columnas alineadas, no una celda por renglón.
    • Solo se lee el texto de las diapositivas. Las notas del orador no se incluyen: usá Extraer notas del orador.
    • El texto de imágenes (capturas con letras) no se reconoce: solo se extrae texto real.

    Preguntas frecuentes

    ¿Mantiene el formato (negritas, colores)?

    No, el resultado es texto plano.

    ¿Funciona con .ppt?

    No, solo .pptx.

    ¿Incluye el texto de gráficos o de formas de texto?

    Incluye el que está dentro de cuadros de texto y tablas de las diapositivas.

    ¿Puedo cargar varias presentaciones?

    No, una por vez.
