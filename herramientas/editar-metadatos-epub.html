    Espacio publicitario

    Solo se cambian el título, el autor y el idioma dentro del archivo del libro: los capítulos, la portada, las imágenes, los estilos, el índice y el resto de los datos (como el ISBN) quedan exactamente igual.

    Cómo editar el título, el autor y el idioma de un EPUB

    Los libros electrónicos descargados de distintas fuentes suelen traer títulos mal escritos, autores en blanco o el idioma incorrecto, y eso desordena tu biblioteca en el lector. Con esta herramienta corregís el título, el autor y el idioma de un EPUB sin tocar el contenido del libro. Los capítulos, la portada, las imágenes, los estilos, el índice y datos como el ISBN quedan exactamente iguales.

    Paso a paso

    1. Arrastrá tu archivo .epub o hacé clic para elegirlo.
    2. Cuando aparezcan los campos, revisá los valores actuales y editá «Título», «Autor» e «Idioma (código, ej. "es", "en")».
    3. Tocá «Guardar y descargar».
    4. Cuando aparezca «Listo», tocá «Descargar EPUB».

    Consejos

    • El idioma se escribe con su código corto: «es» para español, «en» para inglés, «fr» para francés, «pt» para portugués.
    • Si dejás el autor vacío, se quita ese dato del libro. El título y el idioma son obligatorios: si los dejás vacíos se usa «Documento» y «es», respectivamente.
    • Además del dato principal, la herramienta actualiza el nombre para ordenar por autor (en libros EPUB 3), la fecha de última modificación y el título del índice antiguo, que algunos lectores muestran.
    • El archivo descargado toma como nombre el título nuevo.

    Preguntas frecuentes

    ¿Puedo cambiar la portada o la descripción?

    No, solo título, autor e idioma.

    ¿Funciona con un libro con varios autores?

    El campo edita el primer autor registrado.

    ¿Puedo editar un EPUB con DRM?

    No es el objetivo de la herramienta; el contenido cifrado no se modifica.

    ¿Qué pasa si el archivo no es un EPUB válido?

    Aparece un aviso con el motivo, por ejemplo que falta el archivo de contenedor o el .opf.
