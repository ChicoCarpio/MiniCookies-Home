Términos de uso

Objetivo de este sitio

Herramientas Ofimáticas existe para darte acceso a herramientas de oficina de uso cotidiano (PDF, Word, Excel/CSV, PowerPoint, EPUB, Markdown y Texto plano) de forma gratuita y segura, sin que tengas que instalar ningún programa y, sobre todo, sin que tengas que confiar tus archivos a un servidor ajeno: todo el procesamiento ocurre dentro de tu propio navegador (ver Política de privacidad).

Un servicio gratuito, sostenido con publicidad

El uso de todas las herramientas de este sitio es gratuito, no requiere registro ni cuenta de usuario. El proyecto se sostiene mediante espacios de publicidad (Google AdSense) — no cobramos por usar ninguna herramienta.

Las herramientas de este sitio se ofrecen "tal cual" (as is), sin garantía de ningún tipo, expresa o implícita. Aunque cada herramienta se prueba antes de publicarse, no garantizamos que el archivo que generes o modifiques acá (PDF, Word, Excel, EPUB, imagen u otro) esté libre de errores, sea una copia perfecta del original, o resulte apto para el uso específico que le querés dar (por ejemplo, un trámite legal, académico, notarial o administrativo).

Como usuario, sos vos quien debe revisar y verificar el archivo resultante antes de usarlo, presentarlo o entregarlo a un tercero. No nos hacemos responsables por pérdidas de información, daños, rechazos de trámites, ni ningún otro perjuicio directo o indirecto derivado del uso de los archivos procesados o generados con este sitio. Te recomendamos conservar siempre una copia del archivo original antes de procesarlo.

No está permitido usar este sitio para procesar contenido ilegal, que infrinja derechos de autor de terceros, o para cualquier otro fin contrario a la legislación vigente. Tampoco está permitido el uso automatizado (scripts, bots) orientado a sobrecargar el servicio.
