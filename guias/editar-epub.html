Cómo editar un EPUB: título, autor, idioma y capítulos

«Editar un EPUB» puede querer decir dos cosas distintas. Una es corregir los datos del libro (título, autor, idioma), que es lo que ordena tu biblioteca en el lector. La otra es cambiar su estructura: pasar un capítulo al principio o quitar un prólogo que no querés. Cada una tiene su herramienta, y ninguna toca el texto de los capítulos.

Corregir el título, el autor y el idioma

Los libros bajados de distintas fuentes suelen traer títulos mal escritos, autores en blanco o el idioma equivocado, y eso desordena la biblioteca. Con Editar metadatos de un EPUB:

  1. Arrastrá tu archivo .epub o hacé clic para elegirlo.
  2. Revisá los valores actuales y editá «Título», «Autor» e «Idioma (código, ej. "es", "en")».
  3. Tocá «Guardar y descargar».
  4. Cuando aparezca «Listo», tocá «Descargar EPUB».

Los capítulos, la portada, las imágenes, los estilos, el índice y datos como el ISBN quedan exactamente iguales.

Detalles que conviene saber

  • El idioma se escribe con su código corto: «es» para español, «en» para inglés, «fr» para francés, «pt» para portugués.
  • Si dejás el autor vacío, se quita ese dato del libro. El título y el idioma son obligatorios: si los dejás vacíos se usa «Documento» y «es».
  • Además del dato principal, la herramienta actualiza el nombre para ordenar por autor (en libros EPUB 3), la fecha de última modificación y el título del índice antiguo, que algunos lectores muestran.
  • El archivo descargado toma como nombre el título nuevo.
  • Con varios autores, el campo edita el primero registrado. No se pueden cambiar la portada ni la descripción.

Reordenar o quitar capítulos

Con Administrar / reordenar capítulos cambiás el orden de lectura o eliminás capítulos:

  1. Arrastrá el archivo .epub a la zona de carga o hacé clic para elegirlo.
  2. Aparece la lista de capítulos con sus títulos, en el orden de lectura del libro.
  3. Arrastrá cada capítulo hasta la posición que quieras. Para quitar uno, tocá la ✕ de su fila.
  4. Tocá «Descargar reordenado» y después «Descargar EPUB». El archivo se llama «libro-reordenado.epub».

Detalles que conviene saber

  • Al guardar solo cambian el orden de lectura y el índice: se conservan estilos, fuentes, portada y metadatos.
  • Cuando quitás capítulos, también se eliminan las imágenes que quedaron sin uso.
  • No hay botón de deshacer: si te equivocás, volvé a cargar el archivo.
  • No se puede dejar el libro sin capítulos.
  • La herramienta trabaja con los capítulos tal como los define el libro. Si el EPUB tiene todo el texto en un único archivo interno, aparece como un solo capítulo.

Qué no se puede hacer aquí

  • Cambiar el texto de los capítulos. Estas herramientas no editan el contenido.
  • Libros con DRM (protección anticopia): el contenido cifrado no se modifica.
  • Si el archivo no es un EPUB válido, aparece un aviso con el motivo (por ejemplo, que falta el archivo contenedor o el .opf).

Otras cosas que se pueden hacer con un EPUB

  • Juntar varios libros en uno: Unir varios EPUB.
  • Partir un libro por capítulos: Dividir EPUB.

Resumen

Para ordenar tu biblioteca, corregí título, autor e idioma con Editar metadatos de un EPUB; para cambiar qué capítulos tiene un libro y en qué orden, usá Administrar / reordenar capítulos. En ambos casos el contenido de los capítulos queda igual; guardá el original por si querés volver atrás.
