Markdown y asistentes de IA: cómo preparar tus documentos

Cuando le pasás un documento a un asistente de IA, el formato en el que llega importa. Un PDF o un Word son archivos pensados para imprimir o editar, y el texto que contienen va mezclado con información de diseño. Markdown, en cambio, es texto simple con una estructura explícita. Esta guía explica qué es, por qué suele ser una buena opción para trabajar con asistentes y cómo convertir tus documentos con las herramientas del sitio.

Qué es Markdown

Markdown es una forma de escribir texto con estructura usando solo caracteres comunes. Lo creó John Gruber en 2004. Hoy existe una especificación que lo define con precisión (CommonMark) y una variante muy extendida, el Markdown de GitHub, que agrega elementos como las tablas. Los elementos más usados son:

# Título principal
## Subtítulo
- elemento de una lista
1. paso numerado
**negrita** y *cursiva*
[texto del enlace](https://ejemplo.com)

| Columna A | Columna B |
| --- | --- |
| dato | dato |

Y los bloques de código se encierran entre tres comillas invertidas. Un archivo Markdown es un archivo de texto (normalmente con extensión .md), así que se abre en cualquier editor.

Por qué es un buen formato para un asistente de IA

Estas son ventajas de uso habitual, no garantías: un asistente puede equivocarse con cualquier formato. Pero hay razones concretas para preferir Markdown.

  1. Les resulta familiar. Los modelos de lenguaje se entrenan con grandes cantidades de texto que incluye documentación, repositorios y foros escritos en Markdown, y los asistentes suelen responder usando Markdown (títulos, listas, tablas y bloques de código). Por eso suele ser un formato con el que se desenvuelven bien.
  2. La estructura es explícita. Un título es una línea que empieza con #; una lista, líneas con guion; una tabla, filas separadas por barras. No hay que deducir por el tamaño de la letra qué es un título, como ocurre en un PDF.
  3. Suele ocupar poco. El mismo contenido en HTML necesita etiquetas de apertura y cierre, y en un archivo Word el texto viaja dentro de un XML con muchas instrucciones de formato. En Markdown la marca suele ser de uno o unos pocos caracteres. Menos «ruido» suele significar que cabe más contenido útil en el espacio de entrada que admite el asistente, aunque cuánto cambia depende del texto y del asistente.
  4. Es fácil de dividir. Si el documento es largo, los encabezados marcan puntos naturales de corte. Podés mandar un capítulo por vez, o pedir un resumen de cada sección.
  5. Se pega directo en un chat. Es texto plano: no pierde nada al copiarlo y pegarlo, y lo que ves es lo que recibe el asistente.
  6. Es portable y versionable. Un .md se abre en cualquier sistema y se puede guardar en un repositorio para ver qué cambió entre versiones.

Cómo convertir tus documentos

Desde un PDF

Con PDF ↔ Markdown elegí la dirección «PDF → Markdown», arrastrá uno o varios PDF y pulsá «Convertir a Markdown». Con un solo archivo ves el texto en pantalla y podés copiarlo o descargar el .md; con varios, descargás un .zip con un .md por PDF.

Qué se conserva: se detectan títulos cuando la letra es más grande que la del texto normal, y también listas y tablas simples. Cada página se separa con una línea ---. Un texto que se repite en muchas páginas, como un encabezado corrido o el número de página, no se toma como título.

Qué no se conserva: no se mantienen negritas ni cursivas, no se extraen las imágenes, y los diseños complejos (columnas, tablas con celdas combinadas, textos en cuadros) pueden salir desordenados.

Desde un PDF escaneado

Un PDF escaneado es una imagen sin texto, y PDF ↔ Markdown avisa que no encontró texto. Primero pasalo por OCR de PDF e imágenes escaneadas, que lo reconoce y te da un PDF con texto y un .txt. Luego convertí ese PDF a Markdown. El OCR está pensado para texto impreso; la letra manuscrita o las fotos borrosas pueden salir con errores.

Desde un Word

Con Markdown ↔ Word elegí «Word → Markdown» y arrastrá tus .docx. Se conservan títulos, negritas, cursivas, listas y tablas, además de cuadros de texto y notas al pie (que van al final, numeradas). No pasan los encabezados y pies de página, los comentarios ni el texto de SmartArt y gráficos. Las imágenes se guardan en una carpeta junto al .md, por eso la descarga es un .zip. Markdown no tiene celdas combinadas, así que una tabla con ellas pierde esa estructura. Solo acepta .docx, no .doc antiguos.

Desde un EPUB

Con EPUB ↔ Markdown podés pasar un libro sin DRM a Markdown. Cada capítulo queda separado por una línea --- y las tablas pasan como tablas de Markdown. Las imágenes del libro no se incluyen como archivos aparte.

Desde una página web

Markdown ↔ HTML convierte en las dos direcciones. Si pegás el HTML de una página completa, los menús o scripts también pasan a texto, así que conviene limpiar el resultado.

Un flujo de trabajo en cuatro pasos

  1. Convertir. Elegí la herramienta según el origen: PDF, Word o EPUB. Si el PDF es un escaneo, pasá antes por el OCR.
  2. Revisar y limpiar. Abrí el .md en cualquier editor de texto. Buscá encabezados mal detectados, párrafos cortados a mitad de frase, tablas rotas y restos como números de página. Unos minutos acá evitan que el asistente trabaje sobre texto confuso. Si tenés una tabla, Tabla Markdown ↔ CSV la pasa a CSV y viceversa.
  3. Dividir si es largo. Cada asistente admite una cantidad limitada de texto por conversación. Con Dividir Markdown cortás el archivo en cada encabezado de primer o segundo nivel y descargás un .md por sección en un .zip. Administrar / reordenar secciones de Markdown deja quitar las secciones que no hacen falta o reordenarlas. Con Tabla de contenidos de Markdown generás un índice del documento, útil para ubicar qué sección enviar. Los enlaces y las imágenes se copian tal cual, así que revisalos tras dividir.
  4. Pegar con una instrucción clara. Indicá primero qué querés y después pegá el contenido. Por ejemplo: «A continuación te paso el capítulo 3 de un manual. Hacé un resumen de cinco puntos y listá las decisiones que requieren aprobación». Para varias partes, avisá cuántas son y mandalas de a una.

Límites y precauciones

  • La conversión es automática y puede cometer errores. Siempre revisá el resultado antes de apoyarte en él.
  • Que el formato sea claro no garantiza que el asistente interprete bien el contenido: sigue pudiendo equivocarse o inventar, y sus respuestas hay que contrastarlas con el original.
  • Si el documento contiene datos personales o confidenciales, pensá a qué asistente lo vas a pasar y qué condiciones de uso tiene, antes de pegarlo.
  • Un archivo muy largo se puede cortar o ignorar en parte si supera el límite del asistente; dividirlo evita esa pérdida.

Preguntas frecuentes

¿Se pierde el formato al pasar a Markdown? Se pierde lo que Markdown no puede expresar (colores, tipos de letra, columnas). Desde un PDF tampoco se mantienen negritas ni cursivas.

¿Puedo convertir varios archivos a la vez? Sí, PDF ↔ Markdown, Markdown ↔ Word y EPUB ↔ Markdown aceptan varios archivos y devuelven un .zip con un .md por archivo.

¿Y si necesito volver de Markdown a Word o PDF? Las mismas herramientas funcionan en ambas direcciones. El PDF generado desde Markdown es sencillo (títulos, listas y párrafos).

Resumen

Markdown es texto simple con estructura explícita, compacto y fácil de dividir, por eso suele ser un buen formato para dar documentos a un asistente de IA. Convertí tu PDF, Word o EPUB con las herramientas del sitio (con OCR previo si el PDF es un escaneo), revisá el resultado, dividilo por secciones si es largo y pegalo junto con una instrucción clara.
