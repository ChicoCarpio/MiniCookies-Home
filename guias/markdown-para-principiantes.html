Markdown para principiantes: qué es y cómo pasarlo a Word, HTML o PDF

Escribiste unas notas con almohadillas y asteriscos, y al pegarlas en un correo aparecen tal cual, con los # y los ** a la vista. No hay nada roto: Markdown es texto plano con marcas, y el formato aparece solo cuando un programa las interpreta. Esta guía enseña las marcas básicas y cómo llevar el texto a Word, HTML o PDF con las herramientas del sitio.

Qué es Markdown

Un archivo de Markdown suele terminar en .md y se abre en cualquier editor de texto. Las marcas son caracteres que ya tenés en el teclado, y el programa que lo muestra las convierte en títulos, negritas o listas. Lo vas a encontrar en notas, en los README de proyectos de software y en la documentación técnica.

La sintaxis básica

Estas son las marcas que más vas a usar:

# Título grande
## Subtítulo
**negrita**, *cursiva* y ~~tachado~~
- un elemento de lista
1. un paso numerado
[texto del enlace](https://ejemplo.com)

Un título empieza con almohadillas y un espacio: una almohadilla es el nivel más alto, y se puede llegar hasta seis. Entre dos asteriscos va la negrita, entre uno la cursiva, y entre dos virgulillas el tachado. Una lista usa guion o número, y un enlace es el texto entre corchetes seguido, pegado, de la dirección entre paréntesis.

Una tabla usa barras verticales, y una línea de guiones debajo del encabezado la marca como tabla. Un bloque de código va entre dos líneas de tres comillas invertidas.

Los errores que dejan el texto sin formato

Cuando el formato no aparece, suele ser por uno de estos detalles:

  • #Título sin espacio no es un título: sale como párrafo. Escribilo como # Título.
  • Una tabla sin la línea de guiones debajo del encabezado sale como texto, con sus barras.
  • Un asterisco con espacios, como * así *, no hace cursiva. Pegado al texto, sí.
  • Un guion bajo dentro de una palabra no hace cursiva: nombre_de_archivo se ve tal cual.
  • Una lista numerada que empieza en 2 o más, pegada al párrafo de arriba, se queda como texto. Dejá una línea en blanco antes de cualquier lista.

Un solo Enter no separa párrafos: en la vista previa, las líneas seguidas se muestran juntas. Para empezar un párrafo nuevo, dejá una línea en blanco. Para un salto dentro del mismo párrafo, terminá la línea con dos espacios.

Si necesitás un asterisco o una almohadilla como texto, escribilo con una barra invertida delante (\*, \#). La vista previa, Word y el PDF lo muestran sin convertirlo en formato.

Ver cómo queda mientras escribís

En Markdown ↔ HTML, con «Markdown → HTML» elegido, escribí o pegá el texto a la izquierda. A la derecha, la «Vista previa» se actualiza mientras escribís. Las tablas, el tachado, las listas de tareas (con - [ ] y - [x]) y los enlaces escritos sueltos, como una dirección web, se ven como en GitHub, que es el estilo que sigue el conversor.

Pasar Markdown a Word

Con Markdown ↔ Word elegí «Markdown → Word». Si tenés archivos .md (también acepta .markdown y .txt), arrastralos y tocá «Convertir a Word». Con uno baja un .docx con el mismo nombre; con varios, un .zip con un .docx por archivo. Si preferís escribir, usá «O escribilo a mano»: ahí tenés el texto con su vista previa, el campo «Nombre del archivo» y el botón «Descargar .docx».

Se conservan títulos, negritas, cursivas, listas y tablas. No hay opciones de estilo, así que el documento sale con el formato por defecto. Si necesitás otra letra o colores, los cambiás después en Word.

Pasar Markdown a HTML

En Markdown ↔ HTML, «Ver código HTML» despliega el código, y otro clic en ese mismo botón lo oculta. Mientras el código está a la vista aparece «Copiar código HTML», que lo lleva al portapapeles para pegarlo en una web o un blog. «Descargar .html» baja una página completa, con su título tomado del primer encabezado, que se abre directo en el navegador.

Pasar Markdown a PDF

PDF ↔ Markdown tiene la dirección «Markdown → PDF». Con «Convertir a PDF» sale un PDF sencillo: hoja A4, letra Helvetica, títulos en negrita, listas con viñeta para las líneas que empiezan con guion o asterisco, y listas numeradas que conservan su número. El formato dentro de cada línea se quita, así que negritas, cursivas y enlaces quedan como texto. Las líneas seguidas se juntan en un párrafo, y las tablas salen como texto corrido. El código va en Courier, línea por línea, tal como está escrito. Los caracteres que Helvetica no tiene, como emojis o alfabetos no latinos, salen como «?», salvo algunas flechas y símbolos comunes, que se cambian por equivalentes como «->».

Si necesitás que el PDF se parezca a la vista previa, escribí el texto en «O escribilo a mano» y tocá «Guardar como PDF / Imprimir». Eso abre la impresión del navegador, donde elegís la opción de guardar como PDF.

Tablas y documentos con muchos títulos

Si el documento tiene muchos títulos, Tabla de contenidos de Markdown agrega al principio un índice con enlaces a cada uno. Para las tablas, Tabla Markdown ↔ CSV pasa una tabla de Markdown a CSV, listo para abrir en Excel, y también al revés, sin escribir las barras a mano.

Preguntas frecuentes

¿Markdown se ve igual en todos lados? Casi. Los títulos, las listas y los enlaces se ven parecido en casi cualquier programa, pero las tablas y el tachado dependen de quien lo muestre.

¿Qué pierdo al pasar Markdown a Word o a PDF? Markdown no tiene colores, tipos de letra ni celdas combinadas, así que esos detalles no llegan a Word. En el PDF, además, se pierden las negritas y cursivas dentro de las líneas, y las tablas salen como texto corrido.

¿Por qué las tablas salen en el PDF como texto corrido? El conversor a PDF no dibuja tablas: junta sus filas en un párrafo. Si necesitás la tabla con sus columnas, escribila en «O escribilo a mano» y usá «Guardar como PDF / Imprimir», que imprime la vista previa tal como se ve.

Resumen

Markdown es texto simple con unas pocas marcas: almohadillas para los títulos, asteriscos para el énfasis, guiones o números para las listas. Escribilo mirando la vista previa de Markdown ↔ HTML, y convertilo a Word, HTML o PDF cuando lo necesites. Si tu documento tiene tablas y necesitás un PDF fiel, imprimí la vista previa en lugar de usar el conversor.
